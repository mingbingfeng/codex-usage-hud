# 专注休息提醒设置区 · 紧凑重构设计稿

可点击原型：[FOCUS_REST_REMINDER_COMPACT_UI_DESIGN.html](./FOCUS_REST_REMINDER_COMPACT_UI_DESIGN.html)

## 目标

在「请作者喝咖啡」页里，专注休息提醒仍是辅助区，二维码是主视觉。  
这次只收紧**提醒设置区本身**：少占高度、去掉装饰性文案，字段与计时语义不变。

## 现状问题

当前实现（`renderer_hud.py` support 面板）纵向堆叠偏松：

1. 标题与开关分行  
2. 状态区独立双卡，和「本轮开始时间」输入重复  
3. 说明文案单独占行  
4. 工作时间 / 午休 / 通知各占一整行  
5. 保存再单独占一行  

## v2 更紧凑原则

相对 v1 再砍一层「解释性 UI」：

| 去掉 | 原因 |
| --- | --- |
| 字段下方 hint（回来即新一轮 / 可校正本轮） | 老用户已知；tooltip 即可 |
| 「时段外暂停」尾注 | 语义由「工作时间」自明 |
| 状态胶囊里的「剩余」二字 | 数字本身就是倒计时 |
| 开关旁「启用/关闭」文字 | toggle 状态自明 |
| 通知行常态长文案 | 仅失败时显示错误；成功用短状态 |
| 大圆角状态 pill 边框装饰 | 改成纯数字/短词，更轻 |
| 标题「专注休息提醒」 | 缩为「休息提醒」 |

保留且必须可见：

- 开关  
- 四个核心数值（时长 / 延后 / 离开 / 本轮开始）  
- 工作时段 + 午休时段 + 午休开关  
- 失败时的通知错误  
- 测试、保存  

## 结构（v2 denser）

```text
休息提醒
├── 顶行：标题 · 开关 · 状态词 · 倒计时
├── 四字段一行（短 label）
│   ├── 时长
│   ├── 延后
│   ├── 离开
│   └── 本轮开始
├── 时段一行两列
│   ├── 工作  09:00 – 18:00
│   └── 午休  12:00 – 13:30  [✓]
└── 底行：通知短状态 · [测试] · [保存]
```

## 文案对照

| 现文案 | v2 |
| --- | --- |
| 专注休息提醒 | 休息提醒 |
| 开启休息提醒 | （无文字，仅 toggle） |
| 专注时长（分钟） | 时长 |
| 稍后提醒（分钟） | 延后 |
| 离开多久算作休息 | 离开 |
| 本轮开始时间 | 本轮开始 |
| 工作时间 / 时段外暂停 | 工作 |
| 午休暂停 + 启用 | 午休 + checkbox/toggle |
| 发送测试通知并预览 | 测试 |
| 保存提醒设置 | 保存 |
| 系统通知已发送 / 待测试 | 通知 OK / 待测；失败才展开错误 |

单位约定：数字输入默认分钟，不再在每个 label 重复写「（分钟）」。可用 `title`/`aria-label` 补全无障碍文案。

## 交互不变

- 全部 setting key 不变  
- 倒计时 1s 刷新  
- 测试仍打开实际 rest overlay  
- 不改 scheduler 语义

- 时段外 / 午休不运行  
- 本轮开始时间可校正当前轮
