# P6.2 Renderer Kernel Phase

- Date: 2026-07-31
- Baseline HEAD: `ddfe29dc72aee19eeeb3231f118157ad557fe16b`
- Scope: Renderer JavaScript kernel and shared lifecycle capabilities
- Status: complete; P6.3-P6.7 remain

## Result

`renderer_assets/kernel.py` now provides the shared context used by the legacy
continuous asset while later P6 phases migrate domain ownership:

- domain registry with deterministic registration order;
- retained payload/domain state;
- storage and CDP binding adapters;
- one replaceable animation-frame slot per concern;
- tracked one-shot frames, timeouts, and intervals;
- replaceable observer slots and listener scopes;
- reverse-order teardown with idempotent release functions;
- an active-generation guard for late asynchronous callbacks.

The assembled script still has one IIFE and one model-catalog boot placeholder.
All Renderer listeners, observers, frames, timers, intervals, storage access,
and binding sends now pass through the kernel contract. `remove()` runs the
kernel teardown before removing the root and style.

## Reinjection And Lifecycle Fixes

The P6.2 audit found and corrected three lifecycle defects:

1. Reinjection briefly called the previous remove function before capturing
   `selectionSeq` and `appliedSeq`. The duplicate early call was removed; the
   script now captures both values, removes the old instance, and restores the
   monotonic sequence state in that order.
2. Synthetic Model Picker items no longer register per-node listeners in the
   global teardown ledger. Selection is delegated through two document-level
   listeners, detached menus can be collected, and reinject/remove deletes
   stale synthetic items.
3. Background-usage fetch abort controllers are registered with teardown.
   Late background-usage and active-session fallback callbacks stop updating
   DOM/global state after their context is disposed.
