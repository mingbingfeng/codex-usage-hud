8 组件细则 实现对照用
进度语义
阶段百分比：按 6 步权重累加（例 12/16/8/40/12/12），不是文件数/全盘。单阶段内部可叠加不确定细条。
摘要跳动：tabular-nums；仅累计已 complete 的 group 字节；扫描中标签为「累计可清理（扫描中）」。
刚发现：行背景蓝渐变 + 角标，约 1.2s 后消退；同帧最多高亮 1–2 行。
确认按钮：scanning / accepted 全程 disabled；仅 preview + token 就绪可点。
文案字典（中性）
stage.hud → HUD 诊断
stage.codex → Codex 临时项
stage.processes → 相关应用状态
stage.caches → 应用与开发缓存
stage.backups → 旧清理备份
stage.sqlite → 历史数据库
stage.preview → 生成默认安全预览
session.merge → 归并主会话与子任务
a11y
content 区 aria-busy="true"；阶段变化 aria-live="polite" 播报 「第 3 步，应用缓存，已发现 2 组」。取消按钮可键盘聚焦；扫描中分段 tab 可切换查看，但对方 tab 若也在 busy 则各自锁定主操作。
与现有 payload 扩展点（示意）
operation: {
  state: "scanning",
  progress: 33,                 // 阶段权重
  phase: "caches",              // 新增
  phaseLabel: "应用与开发缓存", // 中性
  phaseIndex: 3,
  phaseCount: 6,
  discoveredGroups: 2,          // 新增
  discoveredBytes: 241172480,   // 新增
  elapsedMs: 7000,              // 可选由 UI 自计
  partialGroups: [ ... ]        // 或 inventory 增量
}
本屏为规格便签，不进入产品 UI。实现时 partialGroups 不得带绝对路径；与 safe-cleanup-contracts 一致。

方案 C 交互合约（评审用）

视觉稿冻结这些规则后，再进入实现；未标注「可选」的为默认应做项。

进入

  • 触发：扫描垃圾 / 重新扫描 / 扫描会话
  • <150ms：启动壳或扫描条
  • 按钮：主 CTA 禁用 + 取消可选
  • 不：后台静默扫

进行中

  • 阶段条 + 当前中性文案
  • 摘要累计跳动（蓝灰扫描态）
  • 行：已发现 / 当前 / 排队占位
  • 刚发现短暂高亮

完成 / 失败

  • 完成：收起扫描条 · 摘要变绿 · 确认可用
  • 失败：错误空态 + 重试
  • 取消：回空态或保留旧 revision
  • 重扫：遮罩旧列表，不闪空

不做

  • 假精确到文件的全盘百分比
  • 扫描中可执行清理
  • 暴露绝对路径 / 凭据
  • 半成品 inventory 的 confirmationToken
