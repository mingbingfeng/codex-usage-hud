# P7.3 Overlay Window Owner Phase

- Date: 2026-08-03
- Scope: detached-overlay Codex window preparation and refocus recovery
- Status: implementation and focused automated evidence complete

## Result

`overlay_window.py` is now the terminal owner for the bounded window-action
slice used by detached overlay session commands:

- standalone Codex window preparation through injected platform ports;
- macOS activation fallback for overlay switches;
- delayed post-switch refocus and current-session click delegation.

`overlay_commands.py` retains thin compatibility adapters that assemble the
existing Codex process, tracker, launch, clock, and sleep dependencies. This
preserves existing private patch paths and keeps command routing, session
backend ordering, and helper IPC behavior unchanged. The new owner has no
PySide/Qt imports and does not create or modify a HUD surface.

## Boundary

This phase does not move session-switch backend construction, command routing,
projection, IPC contracts, or helper supervision. Those remain owned by
`overlay_commands.py`, `overlay_projection.py`, `overlay_ipc.py`, and
`desktop_overlay.py` respectively. Renderer-only direction and event-driven
overlay wakeups remain unchanged.
