# 请作者喝咖啡页 UI 设计稿（v3）

可点击原型：[FOCUS_REST_REMINDER_UI_DESIGN.html](./FOCUS_REST_REMINDER_UI_DESIGN.html)

## 方向

专注提醒是“请作者喝咖啡”页里的辅助功能，赞赏二维码是主内容。页面不新增独立导航、不放大倒计时、不使用大型状态面板；提醒设置放在二维码上方的轻量分隔区，但二维码仍保持更大的视觉面积和页面主次。

```text
请作者喝咖啡
├── 专注休息提醒（辅助区域）
│   ├── 开关 + 当前状态
│   ├── 专注时长 / 稍后提醒
│   ├── 本轮开始时间 / 离开多久算作休息
│   ├── 工作时间 / 午休暂停
│   └── 系统通知状态 + 测试通知
└── 扫码支持（主区域）
    ├── 支付宝二维码
    ├── 微信二维码
    └── 项目说明 / 项目主页
```

## 文案

“离开后重新计时”改为：

> **离开多久算作休息**
>
> 回来时开始新一轮

输入值的含义更直接，也不再依赖“0=关闭”的隐含说明。实现时可以保留 `0` 兼容旧配置，但界面建议用单独的关闭状态表达。

## 时间与通知语义（实现前确认）

1. 修改“本轮开始时间”后，按 `开始时间 + 专注时长` 计算下一次提醒；若已到期，下一次循环立即进入到期状态。
2. 工作时间之外、午休区间内不运行计时，也不发送系统通知。
3. 午休或下班暂停后，恢复时从恢复时刻开始一轮新的专注计时。
4. 到点同时发送系统通知和 HUD 内提示；系统通知失败需要显式显示失败状态，不能静默吞掉。
5. 工作时间按本机时区解释；当前配置按每天生效，不额外增加工作日设置。

## 已确认

- 专注提醒放在二维码上方；二维码仍是页面主视觉。
- “发送测试通知”保留在提醒设置中，系统通知失败需要可见状态。
