## Result

`renderer_session_ports.py` is now the terminal owner for
`RendererSessionPorts`, the frozen data-only port contract passed from the
composition root into `run_renderer_hud_session`. Its `from_mapping` method
only validates and materializes declared bindings. It does not construct
resources, start watchers, touch CDP, read files, or select a HUD surface.

`renderer_runtime.py` imports and re-exports the class as a compatibility alias,
so existing callers and test helpers keep their import path. The composition
root and `runtime_compat` materialize fields from the new owner directly.
Lifecycle, startup, event-loop, and Qt/Tk behavior are unchanged.
