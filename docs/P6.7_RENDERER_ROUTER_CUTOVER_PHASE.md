# P6.7 Renderer Router Cutover Phase

- Date: 2026-08-03
- Scope: registry-first payload router and removal of the continuous legacy asset
- Status: implementation and automated/package evidence complete

## Result

The manifest contains exactly 18 ordered assets and ends with `15_router`.
The former `legacy.py` continuous asset has been removed. `router.py` now owns
only root creation, root event delegation, payload retention/routing, public
update/remove globals, and bootstrap.

The obsolete P6.1 continuation fragments `fragment_02.py` through
`fragment_08.py`, their unused `shared_head.py`, and the one-off extraction
tool `tools/migrate_p6_4_assets.py` have also been removed. `fragment_01.py`
remains only as the boot/style source named by the manifest; it is not a
continuous implementation asset.

The router directly invokes registered settings, background-usage,
usage-insights, and session-cleanup owners. Bootstrap installs all P6.3-P6.6
domains in fixed order. The script remains one IIFE with the existing public
globals, bindings, storage keys, payload order, and no-relevant-event/no-work
behavior.

created one root/style and `Session A`; reinjection retained one root/style;
forced root replacement plus a `sessionSwitch`-only payload created one new
root/style, rendered `Session B`, and retained `currentSession`, `budget`, and
`sessionSwitch` domains.

The post-remove probe showed 13 listeners and one mutation observer. Their
stack traces all belong to Playwright CLI hit-target/global-listener
instrumentation, not HUD code; this is the external baseline documented by the
earlier P6 probe.
