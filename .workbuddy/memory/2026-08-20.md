## codex-usage-hud 性能压测（只读，不改代码）
- 角色：性能测试专家；复用 tools/measure_renderer_latency.py harness + 自写规模放大/高频写入探针。
- 产物：output/PERFORMANCE_TEST_REPORT.md + pressure_peak_28mb.{json,md} + pressure_normal_latest.{json,md}。
- 核心发现（高峰期 = Codex 长任务单会话写大）：
  1) JsonlSessionParser.parse_file 全量解析疑似二次方——3000行226ms→20000行11.2s（放大约50倍/数据仅6.7倍），真实28.8MB会话 P90=287ms，超50ms预算5.7倍。
  2) 单 tick 增量解析+payload 中位~120ms(P90 134ms)，事件驱动刷新被锁在7-8Hz。
  3) 常态3.1MB会话回归预算已FAIL（parse_full 67.6ms、payload 27.7ms）。
- 优化方向(P0)：增量续读O(1)尾部游标、payload只做增量diff、超大会话(>50MB)惰性/节流解析移出main tick；P1回归预算分规模基准表 + watcher事件驱动告警。
- 关键文件：core/parser.py(全量解析入口), renderer_file_events.py(文件事件/轮询兜底), renderer_event_loop.py。
