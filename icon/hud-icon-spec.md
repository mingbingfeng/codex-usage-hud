# Codex Usage HUD — 项目图标设计方案

设计目标：一枚**简洁、可无限缩放、富有辨识度**的项目图标，适用于应用启动页、导航栏与文档页眉；
以**抽象/隐喻**手法体现项目主要能力，避免堆砌具象元素（不画窗口、不画货币符号、不画图表堆）。

---

## 1. 设计理念（核心隐喻：用量仪表环）

图标是一个**闭合圆环仪表（Usage Gauge Ring）**。它把项目最关键的几件事压缩进一个图形里：

- **圆环 = HUD 叠加层 + 持续本地监控**
  闭合环形不是一段开口的进度条，而是「始终在线、自我封闭」的视觉暗示——对应 HUD 通过 renderer 注入
  持续悬浮在 Codex 界面之上、且数据只在本地闭环、零遥测不上传。
- **渐变进度弧 = 用量消耗（预算映射）**
  环上约 69% 的青→琥珀渐变弧，代表当前会话 / 今日 / 本周的 token、缓存命中与真实 USD 花费相对预算的消耗程度。
  颜色从青（健康 / 预算内）过渡到琥珀（临近上限 / 成本预警），把「防偷跑、成本透明」直接编码进图形。
- **弧端读数点 = 当前用量刻度**
  进度弧末端的圆点像仪表指针的读数，强调「实时测量」而非静态装饰。
- **中心活动点 = 实时会话**
  圆心的小点（带柔光环）代表「正在活动中的 Codex 会话」——HUD 盯着它是否在跑、最长等待、最慢工具。

一句话：**一只盯在 Codex 之上的活体用量表盘**——这正是 `codex-usage-hud` 在做的事。

## 2. 图形元素 ↔ 项目功能映射

| 图形元素 | 隐喻 | 映射的项目功能点 |
| --- | --- | --- |
| 闭合圆环（轨道） | 叠加层 / 闭环监控 | Renderer 注入式 HUD、始终悬浮显示；纯本地读取 JSONL/SQLite、零遥测、隐私优先 |
| 青→琥珀渐变弧 | 用量消耗 / 预算状态 | 实时 token（输入/缓存/输出/推理）、缓存命中率、USD 估算；日/周预算与提醒阈值 |
| 弧端读数点 | 当前刻度 / 实时测量 | 当前会话用量、刷新时间戳、请求轮次流水 |
| 中心活动点 | 实时会话 / 活动 | 活动状态观察：请求是否在跑、最长等待、最慢工具；桌面完成态气泡 |
| 整体圆润几何 | 轻量、可嵌入 | 跟随 Codex 浅/深主题；轻量无额外窗口 |

## 3. 配色方案

| 角色 | 名称 | 浅色背景变体 | 深色背景变体 | 用途 |
| --- | --- | --- | --- | --- |
| 主色 Primary | Signal Teal | `#1FB6A6` | `#2DD4BF` | 品牌主色、中心活动点、进度弧起点 |
| 辅助色 Secondary | Cost Amber | `#FF9F43` | `#FFB454` | 成本/预算预警、进度弧终点、读数点 |
| 轨道 Track | Neutral | `#D7E0E6` | `rgba(255,255,255,0.18)` | 仪表格（低对比，不抢主体） |
| 启动磁贴底 | Deep Teal | — | `#0E4A47 → #06211F` | 应用图标圆角磁贴背景渐变 |

- **青色**取自「信号 / 在线 / 健康」，契合实时遥测语义；
- **琥珀色**取自「电费账单 / 警示」，把成本透明与防偷跑的诉求可视化；
- 两色渐变让单个图形同时讲完「消耗 + 预算状态」两个故事，无需额外元素。

## 4. 两种显示变体

| 变体 | 文件 | 适用场景 | 说明 |
| --- | --- | --- | --- |
| 浅色背景 | `hud-glyph-light.svg` | 浅色导航栏、文档页眉（浅色主题）、浅色启动图 | 轨道用浅灰，主色/辅助色用饱和实色，保证对比 |
| 深色背景 | `hud-glyph-dark.svg` | 深色导航栏、文档页眉（深色主题）、深色启动图 | 轨道用半透明白，主色/辅助色提亮以适应暗底 |

字形本身为**单色自适应友好**：轨道、弧、两点三层分离，可整体替换为 `currentColor` 做纯单色版（见第 6 节）。

## 5. 应用启动图标

| 文件 | 说明 |
| --- | --- |
| `hud-app-icon.svg` | 圆角磁贴（squircle）深青品牌底 + 浅色字形，自带背景，深浅主题下均可作为启动图标 |

磁贴圆角半径 56（在 256 画布下 ≈22% 圆角），符合主流 OS 应用图标比例；字形居中留白均匀。

## 6. 使用规范

- **最小尺寸**：字形在 16×16px 仍可辨识（环 + 两点）；低于 16px 建议仅保留环与中心点的极简版。
- **留白**：图标外缘至少保留 1/8 画布（≈32px @256）的净空。
- **缩放**：始终使用矢量（SVG）；需要位图时按 16/32/64/128/256/512 导出 PNG，或转 `.ico`/`.icns`。
- **禁用**：
  - 不要拉伸变形或旋转主体；
  - 不要在图形内叠加文字（如 "HUD" 字样）；
  - 不要改变青→琥珀的渐变方向（会破坏「预算内→临近上限」语义）；
  - 浅色变体不要直接放在过亮纯白以外的低对比背景上。

### 单色版（可选）

需要纯单色（例如印章、极小 favicon）时，将轨道、弧、两点统一为同一颜色即可，语义仍成立：
环=监控、弧=用量、点=活动。

## 7. 文件清单

```
icon/
├── hud-glyph-light.svg   # 浅色背景字形（导航栏 / 文档页眉）
├── hud-glyph-dark.svg    # 深色背景字形（导航栏 / 文档页眉）
├── hud-app-icon.svg      # 应用启动图标（深青磁贴）
└── hud-icon-spec.md      # 本说明文档
```

> 几何统一基于 256×256 画布、圆心 (128,128)、环半径 86、弧线宽 18、进度弧 ≈250°（≈69% 填充）。
> 修改填充比例时，保持 `large-arc-flag=1`、`sweep-flag=1`，并重新计算弧端点坐标即可。
